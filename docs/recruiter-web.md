# 招聘 AI Web 控制台

该控制台把 `boss hr ai` 的岗位配置、简历筛选、候选人排序、人工状态和回复草稿能力放到浏览器中。日常招聘操作不需要输入 CLI 命令。

## 启动

### Windows

双击仓库根目录：

```text
start-recruiter-web.bat
```

也可以双击 `start-recruiter-web.pyw`。启动器会优先使用仓库 `.venv` 中的 Python，并自动打开浏览器。

### macOS

运行 `start-recruiter-web.command`，或使用 `python -m boss_agent_cli.web`。

默认地址为 `http://127.0.0.1:8765/`。服务只监听本机回环地址，并为 API 请求生成随机会话令牌。

## 页面能力

- **概览**：候选人总数、建议面试、人工复核、招聘漏斗和 Top 候选人。
- **岗位配置**：保存 JD、岗位名称、BOSS 职位 ID 和高级评分规则。
- **智能筛选**：
  - 浏览器上传多份 JSON 简历并批量评估；
  - 读取授权范围内的 BOSS 投递列表、简历和可选聊天上下文；
  - 显示后台任务进度和失败项。
- **候选人工作台**：评分、推荐等级、风险、追问和维度证据；支持人工更新 `shortlisted/interview/hold/rejected/hired`。
- **回复草稿**：按候选人生成追问、面试邀请、澄清或婉拒草稿，并一键复制。
- **系统设置**：配置 OpenAI-compatible AI 服务、BOSS 登录和 Assisted/Research 模式。

## 推荐流程

1. 打开“系统设置”，保存 AI 服务配置。
2. 点击“打开登录窗口”，在浏览器完成 BOSS 登录。
3. 新建岗位，填写 JD；需要读取 BOSS 候选人时，同时填写 BOSS 职位 ID。
4. 默认 Assisted Mode 可处理本地上传简历。
5. 需要读取 BOSS 投递和简历时，切换 Research Mode，并理解账号、数据授权和平台风险。
6. 在“智能筛选”启动任务，在页面顶部查看实时进度。
7. 在“候选人工作台”进行人工复核和阶段更新。
8. 复制回复草稿到 BOSS 官方页面发送。

## 安全边界

- Web 服务只能绑定 `127.0.0.1` 或 `localhost`。
- API 使用进程启动时生成的随机令牌；令牌只注入本地静态脚本。
- API Key 继续使用项目已有的 Fernet 机制加密保存。
- 年龄、性别、照片、婚育、联系方式等字段不会进入 AI 评分输入。
- 所有 AI 结论和回复草稿都要求人工复核。
- Web 控制台不会自动发送 BOSS 消息，`messages_sent` 始终为 `0`。
- 遇到验证码、账号验证、风控提示或平台限制时应立即停止并回到官方页面处理。

## 数据目录

默认数据仍保存在 `~/.boss-agent/`。Web 控制台和 CLI 使用相同的数据结构，因此岗位、评估、状态和草稿可以互相读取。
