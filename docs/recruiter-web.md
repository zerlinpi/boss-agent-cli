# 招聘 AI Web 控制台

该控制台将岗位配置、简历解析、AI 评分、候选人流转、回复草稿和审计记录集中到浏览器中。日常使用不需要输入命令行。

## 启动

### Windows

双击仓库根目录：

```text
start-recruiter-web.bat
```

启动器优先使用仓库 `.venv` 中的 Python，并自动打开浏览器。运行期间保留一个最小服务窗口；关闭窗口即可停止控制台。

### macOS

运行：

```text
start-recruiter-web.command
```

首次运行时，macOS 可能要求在“隐私与安全性”中确认打开。

默认地址为 `http://127.0.0.1:8765/`。服务只监听本机回环地址，每次启动生成随机 API 会话令牌。

## 推荐工作流

1. 在“设置”中配置 AI 服务。
2. 创建岗位并粘贴 JD。
3. 点击“AI 生成评分规则”，检查硬性条件、评分维度和推荐阈值。
4. 上传本地简历，或在获得授权后切换 Research Mode 读取 BOSS 投递候选人。
5. 在任务条中查看实时进度；任务历史会跨服务重启保留。
6. 在候选人列表或 Kanban 看板中进行人工复核和阶段流转。
7. 生成追问或面试邀请草稿，人工确认后复制到 BOSS 官方页面发送。
8. 使用 CSV 导出和审计时间线留存招聘过程。

## 页面能力

### 招聘概览

- 候选人总数、建议面试人数、平均匹配分和面试转化率；
- Top 候选人、招聘漏斗和匹配分布；
- 近七天新增候选人与最近操作；
- AI、BOSS 登录和运行模式状态。

### 岗位与评分规则

- 保存岗位名称、岗位标识、BOSS 职位 ID 和完整 JD；
- AI 自动生成岗位画像、硬性要求、评分维度和建议问题；
- 评分规则以 JSON 保存，可人工修改并版本化；
- 岗位标识只允许字母、数字、点、下划线和连字符，防止非法文件路径。

### 本地简历筛选

支持：

- `.json`
- `.txt`
- `.md`
- `.docx`
- `.pdf`

限制：

- 单文件最大 12 MB；
- 单次最多 100 份；
- 浏览器单次上传总量控制在约 45 MB；
- DOCX 解压后最大 32 MB；
- 提取文本最长 120,000 字符，超出部分截断；
- 扫描版 PDF 暂不支持 OCR，应先转换为可复制文本的 PDF。

项目会优先使用 `pypdf`（如果环境中已安装），否则使用基础 PDF 文本提取回退逻辑。复杂字体编码的 PDF 可能仍需先转为 DOCX 或 TXT。

### BOSS 投递候选人筛选

- 读取指定岗位的投递列表；
- 逐人读取在线简历并评估；
- 通过简历和评分规则指纹跳过未变化候选人；
- 可读取最近聊天上下文并为 Top 候选人生成回复草稿；
- 单条草稿失败不会中断整个筛选任务；
- 不自动发送消息。

该功能需要显式 Research Mode。遇到验证码、风控、账号验证或平台限制时应立即停止并回到官方页面。

### 候选人工作台

支持两种视图：

- **列表**：搜索、状态过滤、推荐过滤、排序、批量选择和 CSV 导出；
- **Kanban**：按招聘阶段分列，通过拖拽更新候选人状态。

招聘阶段：

```text
新候选人 → 已入围 → 面试中 → 待定 → 已录用 / 不合适
```

候选人详情包含：

- 总分和推荐等级；
- AI 摘要；
- 优势、风险和待确认项；
- 建议追问；
- 各评分维度及证据；
- 人工状态和备注；
- 回复草稿生成器。

### 任务与审计

任务使用 SQLite 保存：

```text
~/.boss-agent/recruiter-ai/web_tasks.db
```

保留登录、岗位分析、本地筛选和 BOSS 筛选的状态、进度、结果和错误。服务重启时，原先处于 queued/running 的任务会被标记为 `TASK_INTERRUPTED`，不会显示为永久运行。

关键操作使用 JSON Lines 审计：

```text
~/.boss-agent/recruiter-ai/audit.jsonl
```

记录岗位保存、运行模式变化、AI 设置变化、候选人状态变化、筛选完成和回复草稿生成。日志超过约 5 MB 时保留最近 2,000 条，避免无限增长。

## 安全边界

- Web 服务只能绑定 `127.0.0.1` 或 `localhost`；
- API 需要进程启动时生成的随机令牌；
- API Key 使用项目原有 Fernet 机制加密保存；
- 响应设置 CSP、禁止 iframe、禁用摄像头/麦克风/定位权限；
- 文件名使用基础名称处理，岗位和候选人 ID 做安全格式验证；
- CSV 导出对公式前缀进行转义，降低表格公式注入风险；
- 年龄、性别、照片、婚育、联系方式等字段不会进入 AI 评分输入；
- 所有 AI 结论和回复草稿均要求人工复核；
- Web 控制台不会自动发送 BOSS 消息，也不会自动录用或淘汰候选人。

## 数据兼容

默认数据仍保存在 `~/.boss-agent/`。Web 控制台与 CLI 使用相同的岗位、评估、候选人状态和回复草稿结构，可以互相读取。
